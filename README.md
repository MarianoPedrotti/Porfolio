# Portfolio de Mariano Pedrotti

Portfolio construido con Vue 3, TypeScript, Vite y Bootstrap.

## Desarrollo

```bash
npm ci
npm run dev
```

## Validación

```bash
npm run build
```

## Despliegue en Vercel

El proyecto usa `createWebHistory()` y `vercel.json` reescribe las rutas de la SPA a `index.html`. Las rutas no reconocidas se resuelven en el cliente mediante la vista 404 de Vue Router.
